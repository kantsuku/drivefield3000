# Drive Field 3000 要件定義パック

このフォルダは、Claude Code に実装・整理を依頼するための前提資料です。  
目的は、**疾走領域 / Drive Field 3000** の思想・世界観・診断構造・命名構造・UI体験・式神・紋章・データ構造を、実装可能な粒度まで整理することです。

## 実装時の基本方針
- 勝手な世界観の追加はしない
- 勝手な命名量産はしない
- 「分類ツール」に寄せない
- 「開眼」「展開」「疾走領域」という核概念を崩さない
- まずは土台となるデータ構造と体験構造を整理する

## このプロジェクトが目指すもの
本プロジェクトは、単なる診断ツールではありません。  
ユーザーが自分の**成長スパイラル**を開眼し、自分の能力が最も自然かつ必中効果的に通る**疾走領域**を見出し、展開し、習得するためのシステムです。

## 用語一覧（簡易）
- **疾走領域 / Drive Field**: 人が最も自然に加速し、能力を通せる領域
- **開眼**: 自分の疾走領域を知ること
- **展開**: 実際にその疾走領域を開くこと
- **真名**: 結果として表示される漢字2文字
- **式神**: 各疾走領域に紐づく伴走AI
- **紋章**: 各疾走領域に紐づく目のシンボル
