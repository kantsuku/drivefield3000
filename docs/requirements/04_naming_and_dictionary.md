# 04. 命名と辞書

## 命名の基本思想
真名（二語）は、構造の説明ではない。  
状態の象徴であり、印であり、真名である。

## 6文字構造の位置づけ
6文字構造は内部処理用。  
ユーザーにそのまま見せるものではない。

## 命名フロー
診断結果
↓
状態の解釈
↓
象徴抽出
↓
二語（漢字）
↓
読み
↓
英語名

## 二語命名ルール
- 漢字2文字固定
- 日本語として読めることを優先
- 直訳しない
- 解釈から抽出する
- 類似構造でも全く違う二語が出てもよい
- 近い意味でも違う方向の二語が出せる方が理想
- 同じ漢字の使用は最大2回程度を目安に管理

## 英語名ルール
- 二語の直訳でなくてよい
- 世界観として自然でかっこいいことを優先
- 2〜3語程度に収める
- 読みの美しさを重視

## 漢字辞書の目的
真名候補を構成するための母集団。  
意味・読み・音・方向性・使用回数を管理する。

## 漢字辞書の推奨項目
- 漢字
- 読み
- 主カテゴリ
- 副カテゴリ
- 発動方向
- 時間特性
- 音の強さ
- イメージ
- 使用可否
- 使用回数
- メモ

## 類義語群の目的
火系、雷系、深系、音系、知性系、役割系など、  
意味の近い漢字群を束で管理し、命名探索をしやすくする。

## 例
- 火系: 火 / 炎 / 焔 / 燃 / 灼 / 灯 / 燈 / 煌
- 雷系: 雷 / 霆 / 震 / 轟 / 閃 / 電
- 深系: 深 / 幽 / 玄 / 冥 / 沈 / 潜 / 凪 / 澪
- 音系: 音 / 鳴 / 響 / 奏 / 詠 / 歌
- 知性系: 知 / 理 / 識 / 悟 / 計 / 解 / 察 / 観

## 良い例
- 鳴核 / Resonant Core
- 雷閃 / Thunder Flash
- 深脈 / Deep Pulse
- 星継 / Star Link
- 狂華 / Wild Bloom
- 縛律 / Bound Rhythm

## NG例
- 構造の説明そのもの
- 読めない二語
- 漢字の意味が薄く、音も弱いもの
- 似た印象の二語が量産されること
