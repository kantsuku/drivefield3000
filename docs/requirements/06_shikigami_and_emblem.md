# 06. 式神と紋章

## 式神の定義
式神は、各疾走領域に紐づく専用ナビゲーターAIである。  
一般的なチャットAIではなく、**その人の領域前提で起動・展開を補助する存在**。

## 式神の役割
- 今のズレを見抜く
- 弱退化を警告する
- 展開条件を示す
- 今日の一手を返す
- 一般論ではなく、その人の領域前提で返答する

## 式神の性格
- 優しすぎない
- でも味方
- 甘やかさない伴走者
- 厳しさはあるが、否定はしない

## 式神が言ってはいけないこと
- どの領域にも当てはまる一般論
- 単なるポジティブ励まし
- ユーザーの疾走領域と無関係な助言
- 不安を過度に煽る表現

## 紋章の定義
紋章は、各疾走領域に対応する“目”のシンボル。  
式神3000体を最初から描くのではなく、**3000パターンの目の紋章**を設計する。

## 紋章の役割
- 視覚的な識別子
- 真名と対になる印
- 結果画面 / 壁紙 / シェアで使う
- 将来的な文化化の核

## 目の文法
紋章は5層構造で考える。

1. 外周
2. 中間層
3. 核
4. 放射
5. 質感

### 外周例
- 円
- 二重円
- 欠け円
- 花弁
- 刃状
- 渦状

### 中間層例
- 螺旋
- 同心円
- 格子
- 波紋
- 花弁
- 断裂線

### 核例
- 点
- 小円
- 縦線
- 裂け目
- 星
- 渦

### 放射例
- なし
- 3本
- 4本
- 多方向
- 粒子
- 稲妻

### 質感例
- シャープ
- 滲み
- 発光
- 墨
- かすれ
- 透明感

## 軸への対応
- 骨格 → 全体構造
- 外燃 / 内燃 → エネルギーの向き
- 瞬発 / 熟成 → 線の性質
- 出力 → コントラストや密度

## 利用箇所
- 結果画面
- 詳細ページ
- シェア画像
- 壁紙
- アイコン
