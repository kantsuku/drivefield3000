# 01. プロジェクト概要

## サービス名
**疾走領域 / Drive Field 3000**

## サービスの目的
本サービスの目的は、ユーザーの本質を当てることではありません。  
目的は、ユーザーが自分の**成長スパイラルを習得し、自分の能力を最も自然かつ効果的に通せる疾走領域を開眼・展開すること**です。

## これは何ではないか
このツールは、以下ではありません。
- 単なる性格診断
- タイプ分け遊び
- 一般論を返す自己分析チャット
- 当たり外れを競う占い

## これは何か
このツールは、以下です。
- 自分の起動条件を知るための儀式
- 自分の能力が最も通る場を開くシステム
- 成長スパイラルを習得するための奥義習得ツール
- 人生を楽しみながら走るための大技の発見装置

## コアコンセプト
- 人は努力で動かない。フィールドで動く。
- 疾走領域は、人生を楽しむための奥義であり大技である。
- 疾走領域を展開している間、ユーザーの能力は**必中効果的**に通る。
- 診断は「分類」ではなく「開眼」のための儀式である。
- 真名（二語）はラベルではなく、その領域の象徴である。

## ユーザーに起こしたい変化
- 「自分はこういう人間だ」から卒業する
- 「自分が最も自然に走れる場はここだ」と理解する
- 領域を知るだけでなく、実際に展開条件を習得する
- 自分の能力を空振りさせずに通せる感覚を持つ

## MVPの方向性
最初から3000すべてを完成させる必要はない。  
まずは以下を揃える。
1. 診断構造
2. 解釈構造
3. 真名（二語）構造
4. 結果ページ体験
5. 式神導線
6. 紋章（目）の文法

## 将来像

- 壁紙・シェア
- チーム比較
- 紋章や真名の文化化
- 世界観付きのシンボル生成システム
